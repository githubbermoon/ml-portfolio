## Premise

Computational representations can expose relationships and inconsistencies, but every representation also removes context. This study records both the utility and the loss.

The temptation is to think that a text becomes clearer as it becomes more structured. A paragraph becomes sentences; sentences become tokens; names become entities; affinities become edges in a graph. Each step feels like an increase in precision. Yet each step is also a decision about what deserves to survive the crossing.

The page carries knowledge that the schema does not easily admit: hesitation in a correction, proximity in a margin, a change of hand, damage, repetition, and the quiet authority of sequence. These are not decorative accidents. Sometimes they are the argument.

## The double reading

The first reading stays close to the object. It asks what is present, how it is arranged, and which distinctions the source itself makes. The second reading is computational. It asks what can be counted, compared, searched, or transformed across many objects at once.

Neither reading is sufficient alone. Close reading can miss a pattern that only appears at scale. Distant reading can produce a beautiful pattern whose meaning evaporates when we return to the passage.

The work therefore moves in a loop: **encounter → encode → compare → return**. The return is essential. A result is not an answer until it can be examined again beside the source from which it was made.

## What the model leaves out

A data model creates a clean room. It names fields, limits variation, and allows relations to be tested. This cleanliness is useful precisely because sources are untidy, but it becomes dangerous when the clean room is mistaken for the world.

Uncertainty should not be silently resolved for the convenience of a database. Variant readings should remain variant. Missing information should remain visibly missing. A doubtful date is not a precise date with low confidence; it is a different kind of claim.

## Working rules

1. Preserve the original object and a stable reference to it.
2. Record every transformation between source and output.
3. Separate transcription, interpretation, and inference.
4. Make uncertainty legible rather than merely numeric.
5. Treat every visualization as an invitation to inspect, not proof.

These rules slow the system down. That is intentional. The aim is not to process the greatest quantity of text, but to build instruments that sharpen attention without erasing the conditions under which meaning was made.
