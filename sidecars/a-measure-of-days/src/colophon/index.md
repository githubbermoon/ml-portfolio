# A hand-built page about measured time.

This edition treats the essay as an exhibition rather than a document. Its structure alternates spectacle with quiet reading, using scale, interruption and visual return to make a long page feel inhabited.

## Architecture

The page is generated by **Eleventy**. **Nunjucks** supplies the shared document frame; **WebC** supplies reusable chapter and image components; this colophon is written in **Markdown**. **Sass** compiles the visual system, while **Rollup** produces route-aware ES modules.

**Taxi** keeps navigation between this page and the essay continuous. **GSAP**, ScrollTrigger, SplitText and CustomEase handle the motion choreography. **Eleventy Image** creates responsive WebP and JPEG variants of the supplied imagery.

## Typography

The working edition uses Italiana, Source Serif 4 and DM Mono—open-source substitutes chosen to preserve the display, reading and interface roles of the intended commercial families. Licensed webfont files can replace them without changing page composition.

## Acknowledgment

The technical architecture and editorial confidence are inspired by Henry Desroches’ *True Terrors of the New Dark Web*. The implementation, writing and visual system here are original to Kosh.
